# Neues Addon (MSFS 2024)

Hier entsteht ein neues Community-Addon für den Microsoft Flight Simulator 2024. Noch ohne
Inhalt.

## Ein Branch pro Addon

Dieses Repository enthält mehrere Addons, jedes auf einem eigenen Branch mit eigener Historie.
Die oberste Ebene jedes Branches ist das MSFS-Paket selbst (`manifest.json` direkt im Ordner).
Deshalb lädt **Code → Download ZIP** immer genau ein Addon herunter. Vorher auf GitHub über der
Dateiliste den Branch auswählen.

| Addon | Branch |
| ----- | ------ |
| OANS Auto Zoom | [`claude/msfs-2024-kryonierendes-addon-8x1jmr`](https://github.com/GarminBot/Auto-zoom-OANS-FBW-synaptic/tree/claude/msfs-2024-kryonierendes-addon-8x1jmr) (Standard-Branch) |
| dieses Addon | `claude/neues-addon-repo-gkmpaf` |

Wie man ein Community-Addon für MSFS 2024 baut, steht im
[Leitfaden auf dem OANS-Branch](https://github.com/GarminBot/Auto-zoom-OANS-FBW-synaptic/blob/claude/msfs-2024-kryonierendes-addon-8x1jmr/docs/msfs2024-addon-leitfaden.md).
